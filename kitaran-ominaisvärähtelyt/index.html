Kitaran kielen ominaisvärähtelyt

Kiinteästi päistään sidottu kieli voi värähdellä useassa ominaisvärähtelyssä samanaikaisesti. Kielen hetkellinen muoto saadaan laskemalla eri ominaisvärähtelyjen poikkeamat yhteen.

A₁ 0,65
y₁(x,t) = A₁ sin(πx/L) cos(ω₁t)
A₂ 0,35
y₂(x,t) = A₂ sin(2πx/L) cos(2ω₁t)
A₃ 0,20
y₃(x,t) = A₃ sin(3πx/L) cos(3ω₁t)

Ominaisvärähtelyjen summa

t = 0,00
y(x,t) = A₁ sin(πx/L) cos(ω₁t) + A₂ sin(2πx/L) cos(2ω₁t) + A₃ sin(3πx/L) cos(3ω₁t)

Ideaaliselle kielelle ominaisvärähtelyjen taajuudet ovat fₙ = n f₁. Siksi toinen ominaisvärähtely värähtelee kaksi kertaa ja kolmas kolme kertaa perusvärähtelyä nopeammin.

Näytä ominaisvärähtelyn laskentaperiaate

Jokaisen ominaisvärähtelyn poikkeama lasketaan erikseen. Lopuksi poikkeamat summataan. 

y1 = A1 * sin(PI * x / L)
           * cos(omega * t);

y2 = A2 * sin(2 * PI * x / L)
           * cos(2 * omega * t);

y3 = A3 * sin(3 * PI * x / L)
           * cos(3 * omega * t);

y = y1 + y2 + y3;
Näytä, miten kieli piirretään

Kieli piirretään laskemalla poikkeama useassa pisteessä pitkin kieltä ja yhdistämällä pisteet viivaksi. 

for (x = 0; x <= L; x += dx) {

    y = laskeKielenPoikkeama(x, t);

    ruudunX = vasenReuna
              + x * mittakaava;

    ruudunY = tasapainoasema
              - y * pystymittakaava;

    piirraPiste(
        ruudunX,
        ruudunY
    );
}

Fysiikan muuttuja y kertoo kielen poikkeaman tasapainoasemasta. Piirtämistä varten metreinä ajateltu paikka muunnetaan näytön koordinaatiksi.
